# backend

Simple NodeJS + Express backend application.

## Recommended IDE Setup

[VS Code](https://code.visualstudio.com/)

Any IDE of your choice that supports TypeScript should work as well.

## Project Setup

See [root README.md](../README.md) for setup instructions.

Main setup installs, compiles and starts the app.

### Type-Check and Compile

```sh
npm run build
```

### Run Unit Tests with [Vitest](https://vitest.dev/)

```sh
npm run test:unit
```

### Lint with [ESLint](https://eslint.org/)

```sh
npm run lint
```
